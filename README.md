## Description

**kmahjongg** is a KDE Mahjongg solitaire game. The goal is to remove all tiles from the board by matching pairs of identical tiles. Only free tiles (those not covered by other tiles and with at least one free side) can be selected. It features multiple tile sets, layouts, and difficulty levels.

---

## About This Package

This is an **Aurelis Linux** package built as an AppImage. However, it can also run as a regular AppImage on any Linux distribution without requiring installation, FUSE, or root privileges.
